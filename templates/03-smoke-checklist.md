# Smoke чек-лист (web + API)

Мета: за 15–30 хв переконатися, що збірка придатна для подальшого тестування. Будь-який провал = збірку повертаємо, далі не тестуємо.

| Поле | Значення |
|---|---|
| Збірка / commit | |
| Середовище | |
| Виконавець / дата | |
| Результат | ✅ Пройдено / ❌ Не пройдено |

Позначки: ✅ пройдено, ❌ провал (додати ID бага), ⏭ не застосовно.

## Інфраструктура
| # | Перевірка | Очікувано | Статус | Баг |
|---|---|---|---|---|
| S-01 | Health-check (`GET /health`, `/ready`) | 200, всі залежності `up` | | |
| S-02 | Версія збірки на середовищі відповідає очікуваній | збігається з тегом релізу | | |
| S-03 | Міграції БД застосовані | без помилок у логах | | |
| S-04 | Немає нових помилок 5xx / exception у логах після деплою | 0 нових | | |
