## Як користуватися

1. Склонуйте репозиторій або скопіюйте теку `.claude/` у свій проєкт.
2. Відкрийте проєкт у Claude Code.
3. Викликайте агента: «Використай агента lead-qa, склади тест-план для оплати карткою». Скілл `lead-qa` підхоплюється автоматично, коли задача стосується тестування.

## Правила, спільні для всього

- **Спершу ризики.** Кожна задача починається з матриці ризиків: Ймовірність (1–5) × Вплив (1–5).
- **Тест-кейс:** ID, назва, передумови, кроки, дані, очікуваний результат, пріоритет.
- **Баг-репорт:** заголовок, середовище, кроки, фактичний і очікуваний результат, severity, priority, докази.
- **Severity:** Critical / Major / Minor / Trivial. **Priority:** P1–P4 (P1 найтерміновіший).
- **Реліз:** вердикт Go / Go з ризиками / No-Go з відкритими дефектами і непокритими ризиками.
